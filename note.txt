====================================================== TẤT TẦN TẬT VỀ GIT ===================================================
git branch : đang đứng ở nhánh nào.
git branch -a : kiểm tra tất cả các nhánh local và remote.  
git brach -c <tên_nhánh_mới> : tạo ra 1 bản copy từ nhánh hiện tại sang nhánh mới và vẫn ở nhánh hiện tại (thay đổi ở đâu thì chỉ nhánh đó thay đổi).
git branch -b <tên_nhánh_mới> : tạo ra 1 bản copy từ nhánh hiện tại sang nhánh mới và nhảy sang nhánh mới luôn (thay đổi ở đâu thì chỉ nhánh đó thay đổi).
git checkout <tên_nhánh> : chuyển từ nhánh hiện tại sang nhánh khác.
git push -u origin <tên_nhánh_cần_push> : push nhánh mới lần đầu lên github, lần sau chỉ cần dùng git push.
git branch -d <tên_nhánh_cần_xóa> : xóa nhánh local (không thể xóa nhánh đang ở hiện tại hoặc nhánh đã commit nhưng chưa push lên).
git branch -D <tên_nhánh_cần_xóa> : xóa nhánh local đã commit nhưng chưa được push.
git push -d origin <tên_nhánh_cần_xóa> : xóa nhánh trên github.
git merge <tên_nhánh> : hợp nhất nhánh khác vào nhánh hiện tại.
git log : kiểm tra các lần commit (nhấn q để thoát).
git log --oneline : kiểm tra các lần commit chỉ xem id và tên commit.
git checkout <id_của_commit> : để quay lại code tại commit cũ.
Muốn đẩy code cũ lên github thì git checkout <id_của_commit> để quay lại nhánh cũ rồi git checkout -b <tên_nhánh_mới> để tạo 1 bản copy.
từ commit cũ sang nhánh mới và con trỏ sang nhánh mới rồi git push -u origin <tên_nhánh_cần_push> để push lên github.

================================================ CSS =============================================================
font-style : kiểu chữ (italic).
font-family : font chữ (Arial, Halvetica,...).
font-size : cỡ chữ.
text-transform : chuyển hoa thường.
text-align : căn giữa.
line-height : định khoảng cách giữa các dòng.
list-style : tác động lên các thẻ li trong ul và ol.
opacity : quy định độ trong suốt (20%, 50%,...), bao gồm cả nền. Khi set = 0 thì ẩn khỏi giao diện nhưng vẫn chiếm 1 vùng trong đó và tương tác được (vd: copy).
background-image: url() : chèn hình ảnh vào 1 thẻ.
display: khi set = none thì ẩn phần tử khỏi giao diện và xóa luôn cả vùng nó đang chiếm.
visibility : ẩn hoặc hiện element (hidden là ẩn, visible là hiện). Khi hidden thì ẩn khỏi giao diện nhưng vẫn chiếm 1 vùng và không tương tác được.
.class1.class2 : css cho thẻ có cả class1 và class2 (giống điều kiện và).
div p : chọn tất cả các thẻ p là con của thẻ div.
div > p : chọn tất cả thẻ p là con trực tiếp của thẻ div.
h1 + h2 : chọn 1 thẻ h2 liền sát sau thẻ h1.
p ~ ul : chọn tất cả thẻ ul nằm sau thẻ p.
[href] : chọn tất cả các thẻ có thuộc tính href.
[target="_blank"] : chọn tất cả các thẻ có target="_blank.
[title~="pic"] : chọn tất cả các thẻ có thuộc tính title chứa từ pic (phải là 1 từ đơn lẻ) trong title.
[title*="pic"] : chọn tất cả các thẻ có thuộc tính title chứa chuỗi pic (chỉ cần có chuỗi là được) trong title.
[title|="pic"] : chọn tất cả các thẻ có thuộc tính title có từ duy nhất bắt đầu bằng từ pic (pic, pic-123,...). Nhưng pic_123 và pic abc không được.
[title^="pic"] : chọn tất cả các thẻ có thuộc tính title bắt đầu bằng chuỗi pic (không quan tâm space đằng sau).
[title$="1"] : chọn tất cả các thẻ có thuộc tính title kết thúc bằng ký tự 1.
================= Pseudo-class ====================
p:hover : chọn các thẻ <p> khi di chuột qua.
a:active : chọn các thẻ <a> khi nhấn giữ chuột
a:link : chọn các thẻ <a> khi có liên kết chưa truy cập.
a:visited : chọn các thẻ <a> có liên kết đã truy cập.
a:focus: chọn các thẻ <a> đang được click vào.
div:empty : chọn các thẻ <div> không có nội dung.
#home:target : chọn thẻ có id="home" khi trên URL có hash tương ứng (VD: https://domain.com/#home).

p:first-child : chọn các thẻ <p> là thẻ con đầu tiên.
p:last-child : chọn các thẻ <p> là thẻ con cuối cùng.
p:nth-child(2) : chọn các thẻ <p> là thẻ con thứ 2 từ trên xuống. (even: vị trí chẵn, odd: vị trí lẻ, 2n+1: vị trí mong muốn).
p:nth-last-child(2) : chọn các thẻ <p> là thẻ con thứ 2 từ dưới lên.
p:only-child : chọn các thẻ <p> là thẻ con duy nhất.

p:first-of-type : chọn các thẻ <p> xuất hiện đầu tiên trong thẻ cha.
p:last-of-type : chọn các thẻ <p> xuất hiện cuối cùng trong thẻ cha.
p:nth-of-type(n) : chọn các thẻ <p> xuất hiện thứ n trong thẻ cha tính từ trên xuống. (even: vị trí chẵn, odd: vị trí lẻ, 2n+1: vị trí mong muốn).
p:nth-last-of-type(n) : chọn các thẻ <p> xuất hiện thứ n trong thẻ cha tính từ cuối lên.
p:only-of-type : chọn các thẻ <p> xuất hiện duy nhất trong thẻ cha.

.top:not(p) : chọn các thẻ có class="top" loại trừ thẻ p.

================= Box Model ============================
Box model : trình duyệt luôn coi mỗi phần tử là 1 box - hộp chữ nhật.
Nội dung (width, height): hình ảnh, text, video,...
padding: khoảng đệm nội dung và viền (không chứa nội dung).
border: viền của phần tử (viền nét liền, đứt,...).
margin: khoảng cách với các phần tử liền kề khác.
height x width = content + padding + border. (không bao gồm margin) 

padding-top, padding-bottom, padding-left, padding-right.
padding: 20px; //cả 4 hướng
padding: 20px 10px; //trên dưới 20px, trái phải 10px.
padding: 20px 10px 40px; //trên 20px, trái phải 10px, dưới 40px.
padding: 20px 10px 40px 50px; //trên 20px, phải 10px, dưới 40px, trái 50px.

border: <độ rộng> <kiểu viền> <màu viền>
border: 10px solid blue (cho cả 4 border top left bottom right).
border viết tường minh: (giống quy tắc padding).
border-width: 10px 20px 30px 40px 
border-style: solid dashed double dotted
border-color: blue yellow red pink
border-top, border-bottom, border-left, border-right.
border-radius: bo góc.
border-top-right-radius: 10px;
border-top-left-radius: 10px;
border-bottom-left-radius: 10px;
border-bottom-right-radius: 10px;
border-radius: 30px; (cả 4 góc)
border-radius: 30px 50px; //(top-left & bottom-right), (top-right & bottom-left)
border-radius: 30px 50px 70px; //(top-left), (top-right & bottom-left), (bottom-right)
border-radius: 30px 50px 70px 80px //mỗi góc một giá trị (theo chiều kim đồng hồ từ góc trên trái).
1 số kiểu viền:
dashed: đường nét đứt.
dotted: viền là các chấm dot.
double: viền 2 đường song song liền nhau.
groove: viền 3D.
ridge: viền 3D.
inset: viền 3D.
outset: viền 3D.

margin: sử dụng để xác định khoảng cách giữa các phần tử trên trang.
margin-top, margin-bottom, margin-right, margin-left.
margin: 20px; //cả 4 hướng
margin: 20px 10px; //trên dưới 20px, trái phải 10px.
margin: 20px 10px 40px; //trên 20px, trái phải 10px, dưới 40px.
margin: 20px 10px 40px 50px; //trên 20px, phải 10px, dưới 40px, trái 50px.
Để căn giữa: set margin: 0 auto //trên dưới 0, trái phải auto và width = 700px. Nếu muốn chữ căn giữa trong ô luôn thì dùng text-align: center.

========================= Margin Collapse =======================
Margin collapse: là hiện tượng chồng lặp thuộc tính margin khi 2 phần tử liền kề cùng thiết lập margin với phần tử còn lại theo chiều dọc, chiều ngang không bị.
(VD: 1 cái margin-bottom: 50px, 1 cái margin-top: 70px -> 2 box1 và box2 chỉ cách nhau theo chiều dọc 70px vì 70px > 50px).
Cách khắc phục: chỉ margin theo 1 chiều nhất quán, từ trên xuống hoặc dưới lên.
Trong trường hợp bắt buộc: thêm vào thẻ cha thuộc tính display: flex và flex-direction: column.
TH2: xảy ra với quan hệ cha con: khi set margin cùng chiều cho thẻ cha và thẻ con thì sẽ bị collapse, kích thước nào lớn hơn sẽ quyết định.
Cách khắc phục cho TH2: thêm vào thẻ cha thuộc tính display: flex và flex-direction: column.

========================= Outline ==========================
Outline là đường viền bao quanh mép ngoài cùng của đối tượng, tính từ phần cuối cùng có set giá trị.
outline: 20px solid blue;
Không vẽ được nhiều chiều như border.
outline-offset: 10px //cách phần cuối có set giá trị ra 1 khoảng 10px.

===================== box-sizing ======================
box-sizing: content-box và border-box. Thực tế dự án ta sử dụng border-box thường xuyên hơn, để kích thước khớp với thiết kế, tránh phải tính toán lại phần nội dung.
Khi không set box-sizing thì mặc định là content-box.
Khi box-sizing: content-box, width, height là kích thước của vùng content.  
Khi box-sizing: border-box, width, height là kích thước của toàn bộ phần tử bao gồm border, padding, content (thêm padding, border thì giảm content).

======================= Inheritance - Kế thừa ===========================
Inheritance - Kế thừa: Các phần tử con nhận được các giá trị thuộc tính thừa kế phần tử cha.
Các thuộc tính kế thừa chủ yếu liên quan đến văn bản. 

==================== Đơn vị trong CSS ==========================
px: đơn vị tuyệt đối.
%: đơn vị tương đối so với thẻ cha. font-size mặc định trong trình duyệt thường là 16px.
vw (viewport width): chiều rộng theo khung nhìn (phần hiển thị trên browser). VD: 50vw: 50% chiều rộng theo khung nhìn.
vh (viewport height): chiều cao theo khung nhìn (phần hiển thị trên browser).
2em: kích thước gấp 2 lần font-size của thẻ hiện tại hoặc của thẻ cha hoặc thẻ html (thường là 16px). Ưu tiên font-size của nó nếu có set.
3rem: kích thước gấp 3 lần font-size của root element, nghĩa là thẻ html (thường là 16px) và không có kế thừa.
1 rem = 16px -> Nên đổi 1 rem = 10px. Cần thay đổi thẻ html, font-size: 62.5%.
Nên dùng rem vì có thể điều chỉnh 1 cách linh hoạt khi người dùng tăng giảm kích thước trong trình duyệt. Khi cần tăng font-size tất cả 
lên 10% thì chỉ cần thay đổi font-size của html font-size: 72.5% là được.

===================== Font chữ trong CSS ===================
Sans serif: font không có gai ở đầu chữ cái.
serif: font có gai ở đầu chữ cái.
Monospace: font có cùng độ rộng.
Tăng tốc trang web bằng cách thêm các phông chữ hệ thống có sẵn vào body:
body {
  font-family: system-ui, "Segoe UI", Roboto, Helvetica, Arial, sans-serif, "Apple Color Emoji", "Segoe UI Emoji", "Segoe UI Symbol";
}
Nhúng font chữ để bất cứ máy nào cũng hiển thị giống nhau, kể cả máy đó không cài font này. Cách làm:
1. Lên trang fonts.google.com chọn font chữ
2. Thêm font chữ yêu thích vào và bên phải ở trên có mục selected family, copy thẻ <link> vào <head> trước "style.css"
3. Quay lại web copy phần CSS vào body hoặc nơi ưa thích.

font-weight: độ dày của chữ (thường từ 100->900). font-weight mặc định là 400.
font-weight: lighter (độ dày giảm 1 cấp).
font-weight: bolder (độ dày tăng 1 cấp).

line-height: chiều cao giữa các dòng.
line-height: 1.5 hoặc line-height: 150% là như nhau và đều bằng 1.5 lần font-size.

letter-spacing: tăng giảm khoảng cách giữa các ký tự (10px, 20px,...).
word-spacing: tăng giảm khoảng cách giữa các từ (10px, 20px,...).

text-algin: căn text so với box chứa nó (thẻ block, inline).
text-align: justify //căn dàn đều 2 bên.
text-align: left //căn trái (mặc định khi không set text-align).
text-align: right //căn phải.
text-align: center //căn giữa.

text-decoration: none //bỏ gạch chân.
text-decoration: underline //thêm gạch chân.
text-decoration: line-through //thêm gạch ngang chữ.
text-decoration: overline //gạch trên đầu.
text-decoration: underline dotted blue 5px //định kiểu của dấu gạch, màu sắc, kích thước.

text-indent: thụt lề.
text-indent: 40px //thụt lề 40px.

text-transform: capitalize //viết hoa chữ cái đầu của mỗi từ.
text-transform: lowercase //viết thường toàn bộ text.
text-transform: uppercase //viết hoa toàn bộ text.

white-space: quy định về khoảng trắng khi code.
white-space: normal //trạng thái mặc định.
white-space: nowrap //không xuống dòng (kể cả đoạn văn dài chạm tới lề).
white-space: pre //giữ nguyên định dạng code, giống thẻ <pre>.
white-space: pre-line //giữ nguyên định dạng theo line(enter). Nghĩa là tất cả khoảng trắng dư thừa ở mỗi dòng sẽ bị xóa, còn enter(xuống dòng) thừa thì giữ nguyên.

word-break: khi đoạn text dài, người dùng nhập liền nhau thì có thể gây ra vỡ giao diện vì text không bị xuống dòng nên dùng

================================== Background ================================
background-color: nền sẽ đổ vào toàn bộ các phần tính vào kích thước phần tử (border, padding, content).

background-image: ở trạng thái mặc định, hình ảnh sẽ lặp vô hạn, chiếm hết kích thước của thẻ chứa nó.
background-image: url(bg/leaf.png), url(bg/small.jpg)
Khi background-image có 2 url thì url xếp trước sẽ nằm trên và nên để .png được ưu tiên vì nó có thuộc tính trong suốt để có thể thấy nền nằm sau.

background-image: linear-gradient : dải nền chuyển sắc.
background-image: linear-gradient(direction, color-stop1, color-stop2,...).
stop1 = 40%: nghĩa là từ 0% đến 40% màu đầu tiên không chuyển màu.
stop2 = 60%: nghĩa là từ 60% đến 100% màu thứ hai không chuyển màu.
background-image: linear-gradient(62deg, #8ec5fc 0%, #e0c3fc 100%,...)
background-image: linear-gradient(to left, #8ec5fc 0%, #e0c3fc 100%,...).
background-image: linear-gradient(to right, #8ec5fc 0%, #e0c3fc 100%,...).
background-image: linear-gradient(to top left, #8ec5fc 0%, #e0c3fc 100%,...).
% không áp dụng chuyển sắc từng màu.
direction không nhập thì mặc định chuyển màu từ top -> bottom = to bottom. 
Dùng trang https://cssgradient.io/gradient-backgrounds/ để tạo ra màu nền chuyển sắc đẹp mắt.

background-size: điều chỉnh kích thước ảnh nền.
background-size: contain //ảnh vừa khung hình, giữ nguyên tỷ lệ ảnh, không bị mất ảnh, nếu còn khoảng trống, ảnh sẽ bị lặp lại.
background-size: cover //ảnh vừa khớp khung hình, giữ nguyên tỷ lệ ảnh, có thể mất 1 phần ảnh, không bị lặp ảnh.
background-size: 100% //chiều rộng = 100% chiều rộng box (hoặc cũng có thể dùng đơn vị px).
background-size: 100% 100% //chiều rộng = 100% chiều rộng box, chiều cao = 100% chiều cao box (hoặc cũng có thể dùng đơn vị px).

background-position: vị trí bắt đầu đặt ảnh nền (top, top left, top right, left, right, center, bottom, bottom left, bottom right). 
background-position: 0% 0% //phần trăm đầu tiên là trục x, thứ 2 là trục y. Tính từ top left (0% 0%).
%x càng cao dịch phải càng nhiều, %y càng cao dịch xuống càng nhiều.
Có thể dùng px thay cho %.

background-attachment: scroll //mặc định: ảnh sẽ tự động cuộn theo trình duyệt khi kéo lên xuống.
background-attachment: fixed //ảnh cố định khi kéo lên xuống.
background-attachment: local //ảnh cố định cục bộ trong bố cục con.

background-clip: quy định vùng đổ nền.
background-clip: border-box //mặc định, ảnh sẽ đổ vào full kích thước phần từ (border + padding + content).
background-clip: padding-box //ảnh chỉ đổ đến padding.
background-clip: content-box //ảnh chỉ đổ phần content.
background-clip: text
-webkit-background-clip: text //đổ màu nền trong phần text, không hiển thị phần trống ngoài text.
VD:
Kiểm tra xem trình duyệt có hỗ trợ thuộc tính này không rồi mới thực hiện trong code trong ngoặc.

  .test {
    color: transparent;
    background: #eeaeca;
    background: radial-gradient(
      circle,

background-origin: xác định gốc bức ảnh đặt ở vị trí nào (vị trí bắt đầu vẽ hình nền).
background-origin: padding-box //mặc định: gốc ảnh mặc định ở phần padding.
background-origin: border-box //gốc 0,0 của ảnh sẽ ở border. 
background-origin: content-box //gốc 0,0 của ảnh sẽ ở phần content.

Phân biệt giữa background-clip và background-origin:
Background-clip: là chỉ định hình nền được hiển thị ở vùng nào thôi.
Background-origin: là vị trí bắt đầu đặt ảnh (gốc tọa độ của ảnh hay gốc đặt ảnh).

background-repeat: repeat //BG lặp lại cả 2 trục (mặc định).
background-repeat: no-repeat //BG không lặp lại.
background-repeat: repeat-x //BG lặp lại theo trục x.
background-repeat: repeat-y //BG lặp lại theo trục y.

============================= Clip-path ===============================
Tạo 1 vùng cắt, nội dung trong vùng cắt sẽ được hiển thị. 
Nội dung ngoài vùng cắt sẽ bị ẩn đi.
clip-path: circle() //cắt hình tròn.
clip-path: inset() //cắt hình chữ nhật.
clip-path: polygon() //cắt hình đa giác.
VD: 
clip-path: circle(40% at 50% 40%) //bán kính = 40% chiều rộng của phần tử (width) tại x = 50% và y = 50% (x và y là tâm đường tròn).
clip-path: inset(20px 40px) //khoảng cách cắt vào từ các cạnh của phần tử, các đối số giống thuộc tính padding.
Nếu muốn bo góc thì thêm round phía sau các đối số.
clip-path: inset(20px round 15px) //bo cả 4 góc.
clip-path: inset(20px round 15px 20px) //bo theo (top-left & bottom-right), (top-right & bottom-left).
clip-path: inset(20px round 15px 20px 30px) //bo theo (top-left), (top-right & bottom-left), (bottom-right).
clip-path: inset(20px round 15px 20px 30px 40px) //mỗi góc một giá trị (theo chiều kim đồng hồ từ góc trên trái).
clip-path: polygon(x y, x y, x y, x y) //cặp x y là các cặp tọa độ theo các góc theo x,y (giống như chọn ra các điểm cắt rồi nối vào).
Vào web css clip path generator để tự tạo hình mong muốn.

======================== CSS Position =============================
position cho phép điều chỉnh vị trí các phần tử trên trang web.
position: static //mặc định: phần tử sẽ cố định trên trang.

Căn giữa text ở các khối:
display: flex;
justify-content: center;
align-items: center;

position: relative; //định vị so với vị trí ban đầu của nó 1 khoảng x (ở đây phần tử cách cạnh trái 50px). Nhưng chỗ cũ của nó vẫn bị chiếm.
left: 50px;

position: absolute //phần tử thực sự được đưa ra khỏi luồng ban đầu và đưa lên lớp trên so với lớp hiện tại (không chiếm vị trí ban đầu đã chiếm giữ).
1. Nếu không có tổ tiên có position: relative thì phần tử được định vị theo top left corner webpage.
2. Phần tử được định vị theo tổ tiên gần nhất đặt position là relative.

position: fixed //fix cứng phần tử theo viewport (vùng hiển thị nội dung trên màn hình của trình duyệt web) và cũng được đưa ra khỏi luồng lên lớp trên.
inset: 50px //cách đều 4 góc 50px (các đối số tương tự như padding).

position: sticky //định vị phần tử dính lại theo thẻ cha gần nhất có thanh cuộn scroll bar.

=========================================== Page Layout ===============================================
Page Layout: còn gọi là bố cục - dàn trang.
Cơ bản là cách ta xếp đặt khối bố cục con (component layout) lên trên webpage.
Việc xếp đặt giúp cho trang web nhìn đẹp, thu hút người xem, và truyền tải nội dung 1 cách có trật tự, logic.
Component Layout: là các bố cục con, nơi mà: text, images, videos... và các nội dung khác được xếp đặt.
3 cách phổ biến để xây dụng layout với CSS:
1. Float Layout:
float: left //phần tử sẽ bị trôi khỏi luồng bình thường và các phần tử còn lại sẽ bao quanh phần tử đó.
Trong trường hợp muốn 1 phần tử nào đó không bị chèn ép để bao quanh 1 phần tử set layout, ta dùng clear: left (không bị giá trị float bên trái ảnh hưởng), clear: right và clear: both.

======================================= Flex Box ====================================
display: flex //đưa phần tử ra khỏi luồng thông thường, tuân theo các quy tắc riêng (box cha chiếm hết chiều ngang của thẻ cha nó).
Khi set display: flex thì box cha sẽ sinh ra trục main axis (trục ngang) và cross axis (trục dọc).
main start nằm ở bên trái, main end bên phải, nghĩa là main axis hướng từ trái sang phải.
cross star nằm ở trên, cross end nằm ở dưới, nghĩa là cross axis hướng từ trên xuống.
display: inline-flex //box cha chỉ có độ dài vừa với nội dung của các box con trong nó.
gap: 40px //các phần tử cách nhau 1 khoảng 40px.
Các nhóm thuộc tính flexbox:
1. Flex-Container: các thuộc tính cho box cha.
  justify-content
  align-items
  flex-wrap
  align-content
  flex-direction
  flex-flow

2. Flex-Item: các thuộc tính cho các box con.
  algin-self
  flex-grow
  flex-shrink
  flex-basis
  order
  flex

============================== Flex-Container: các thuộc tính cho box cha ===============================
justify-content: sẽ căn các phần tử theo trục main axis.
justify-content: flex-start //mặc định: các item sẽ dồn sang trái (main start).
justify-content: flex-end //các item sẽ dồn sang hướng bên phải (main end).
justify-content: center //các item sẽ nằm giữa khối cha.
justify-content: space-between //các item ngoài cùng sẽ ra sát lề và khoảng cách giữa các item sẽ bằng nhau.
justify-content: space-around //khoảng trắng trái phải các item là như nhau, vì vậy mà khoảng trắng giữa các phần tử gấp đôi khoảng trắng giữa phần tử ngoài cùng và lề.
justify-content: space-evenly //các item cách đều nhau, cách cả lề.

align-items: sẽ căn các phần tử theo trục cross axis.
align-items: stretch //mặc định: kéo giãn các phần tử bằng chiều cao container.
align-items: flex-start //các item sẽ dồn lên trên (cross start).
align-items: flex-end //các item sẽ dồn xuống dưới (cross end).
align-items: center //các item sẽ nằm giữa.
align-items: baseline //các item sẽ căn theo chân phần tử.

flex-wrap: nowrap //mặc định: các phần tử con thì đều nằm trên cùng 1 hàng.
flex-wrap: warp //khi chiều rộng của các phần tử con vượt quá chiều rộng của phần tử cha thì các phần tử con sẽ xuống dòng theo chiều trục cross (đi xuống).
flex-wrap: wrap-reverse //giống wrap nhưng mà sau khi wrap xong thì sẽ đảo ngược thứ tự các dòng (từ cross end lên cross start).

align-content: sử dụng kèm với flex-wrap: wrap, căn theo trục cross. Khác với align-items là align-content áp dụng với 2 hàng trở lên nên cần dùng với flex-wrap: wrap để xuống hàng.
align-content: stretch //mặc định: các phần tử tự kéo dãn thep trục cross lấp đầy box cha.
align-content: flex-start //các item sẽ dồn lên trên (cross start).
align-content: flex-end //các item sẽ dồn xuống dưới (cross end).
align-content: center //các item sẽ căn giữa theo chiều dọc.
align-content: space-around //khoảng trắng trên dưới các  hàng item là như nhau, vì vậy mà khoảng trắng giữa các hàng phần tử gấp đôi khoảng trắng giữa hàng phần tử trên cùng và lề.
align-content: space-between //các hàng item trên cùng và dưới cùng sẽ ra sát lề và khoảng cách giữa các hàng item sẽ bằng nhau.

flex-direction: row //mặc định: hướng trục main axis từ trái sang phải.
flex-direction: row-reverse //hướng trục main axis từ phải sang trái.
flex-direction: column //các item được đặt từ trên xuống dưới, lúc này main axis theo chiều dọc (từ trên xuống dưới), còn cross axis theo chiều ngang (từ trái qua phải).
flex-direction: column-reverse //các item được đặt từ dưới lên trên, lúc này main axis theo chiều dọc (từ dưới lên trên), còn cross axis theo chiều ngang (từ trái qua phải).

flex-flow: cú pháp viết tắt của flex-wrap và flex-direction.
flex-flow: wrap row-reverse //flex-wrap: wrap và flex-direction: row-reverse.



=================================== Flex-Item: các thuộc tính cho các box con ============================
order: mỗi item có order mặc định = 0.
Dùng order để thay đổi thứ tự cho item (theo thứ tự từ order thấp tới order cao).

align-self: sẽ căn các phần tử theo trục cross axis.
align-self: stretch //mặc định: kéo giãn phần tử bằng chiều cao container.
align-self: flex-start //item sẽ dồn lên trên (cross start).
align-self: flex-end //item sẽ dồn xuống dưới (cross end).
align-self: center //item sẽ nằm giữa.
align-self: baseline //item sẽ căn theo chân phần tử.

flex-grow: chia tỷ lệ chiếm (theo main axis) theo trọng số (mặc định = 0, 1, 2, 3,...).

flex-shrink: xác định khả năng co lại của item nếu cần.
Khi số lượng item nhiều lên, các item tự động co lại vị không đủ chỗ chứa.
flex-shrink: 1 //mặc định: tự động co lại nếu chiều rộng box cha không đủ chỗ đến khi đạt min-width.
flex-shrink: 0//không bị co lại.
flex-shrink: 2//co lại nhanh hơn 2 lần so với các item khác.

flex-basis: set main size item (lưu ý main size theo trục main axis).

flex: cú pháp viết tắt của 3 thuộc tính flex-grow, flex-shrink và flex-basis.
flex: 0 1 100px.













====================== Thứ tự ưu tiên của chiều rộng ===========================
1. min-width / max-width 
2. flex-basis
3. width
4. content width
Nếu max-width < flex-basis -> chiều rộng sẽ theo max-width.
Nếu max-width > flex-basis -> chiều rộng sẽ theo flex-basis.
Ở kích thước mặc định, thì max-width = content trong box đó và min-width = kích thước từ dài nhất của content.
